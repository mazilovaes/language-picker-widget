# language-picker-widget

## Figma

Для совпадающих элементов ориентир — [библиотека Default components](https://www.figma.com/design/nuC4KFMiS36uDWDUp9wKGl/). Радиокнопки правой панели соответствуют компоненту radioButton на странице «Радиокнопки».

- [Презентация макета](https://www.figma.com/proto/3Yl72cbdrKTAYTYMby3ACw/%D0%92%D0%B8%D0%B4%D0%B6%D0%B5%D1%82-%D0%92%D1%8B%D0%B1%D0%BE%D1%80-%D1%8F%D0%B7%D1%8B%D0%BA%D0%B0?node-id=5724-40312&p=f&t=lL6EgVaxnYP5xGe7-0&scaling=min-zoom&content-scaling=fixed&starting-point-node-id=5724%3A40312&page-id=5724%3A33184&hide-ui=1)

Кнопки, чекбоксы, сегментированные переключатели, тулбар и навигационные кнопки используют CSS [каталога UI Kit](https://mariesmi.github.io/ui-kit/catalog/#button). Локальные копии находятся в `docs/vendor/ui-kit`. Для собственных стилей демо используется палитра Global Variables / Default Light.

Для локального запуска откройте `docs/index.html`. Демо работает без сборки и не загружает Figma. Ссылки на исходник и презентацию приведены выше для ручной сверки.

Настройки сразу применяются к Design time, обоим примерам Run time и Demo. Галочка принимает настройки, крестик отменяет изменения после последнего применения. Состояние хранится в памяти текущей страницы.

В демо первые семь языков доступны для выбора. Многоточие под меню открывает полный каталог; для недоступного языка выводится уведомление. Это демонстрационные данные, не сведения о доступности переводов продукта.

GitHub Pages публикует каталог `docs` ветки `main`. Изменения в Figma отображаются в оригинальном прототипе; самостоятельную реализацию обновляют отдельно.
